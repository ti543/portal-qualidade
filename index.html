Criar acesso de um usuário novo

Cria o login e já libera os módulos. Se deixar a senha em branco, a pessoa recebe um e-mail para criar a própria senha (recomendado). Se preencher, passe a senha para ela — ela pode trocar depois pelo "Esqueci minha senha".

O login já existe? Vincular pelo UID

Use só se a pessoa já tem login no Firebase (ex.: aparece "e-mail já cadastrado" acima). O UID fica em Firebase Console > Authentication.
